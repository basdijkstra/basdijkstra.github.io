Test automation is about much more than writing automated end-to-end tests. To build an effective and maintainable test automation approach, software engineers need to understand how to test at different levels, how these levels complement each other, and how to integrate automated tests into their development workflow.

And even though AI tools can now generate a significant amount of code for us, understanding the principles and techniques behind good test automation remains essential. You need to know what to ask AI to create, how to evaluate its output, and how to recognise whether your tests provide meaningful feedback.

In this four-day, hands-on bootcamp, you will learn how to design, implement and maintain test automation across the different layers of a software application. From unit testing and mocking to API and integration testing, end-to-end testing with Playwright, and automated build pipelines, we'll explore the tools and techniques that help you build confidence in your software.

What makes this bootcamp different is that we don't work with a collection of unrelated examples. Throughout the five days, we use the same application and codebase. You'll progressively build up its test automation, applying different testing techniques to the same context and seeing how they fit together. This creates an immersive learning experience and helps you understand how the different parts of a comprehensive test automation approach work together.

## What will you learn?

During the bootcamp, we'll explore the different aspects of modern test automation engineering. You'll learn the concepts, see them applied in practice and get plenty of opportunities to put them to work yourself.

#### Test automation strategy

Effective test automation starts with understanding what you're trying to achieve and how automation can help. We'll explore how to approach test automation strategically, how to decide what to test and at which level, and how to make sensible choices about where to invest your automation efforts.

#### Unit testing, mocking and mutation testing

Unit tests are an important part of a fast and reliable feedback process. You'll learn how to write effective unit tests, how and when to use test doubles and mocking, and how mutation testing can help you evaluate the quality of your tests and identify gaps in your test coverage.

#### API and integration testing

Not all important behaviour can be tested effectively through the user interface. We'll explore how to test APIs and the integration between different parts of an application, including how to approach API security testing. You'll learn how to build confidence in the behaviour of your application without relying exclusively on end-to-end tests.

#### End-to-end testing

End-to-end tests allow us to verify that an application works as expected from the perspective of its users. You'll learn how to automate browser-based tests, interact with application functionality and build end-to-end tests that provide useful feedback without becoming unnecessarily fragile or difficult to maintain.

#### Version control and build pipelines

Test automation is part of software engineering, and it should be part of the development workflow, too. We'll look at how to manage test automation code using version control and how to integrate automated tests into build pipelines, so that tests can provide feedback as part of the process of developing and delivering software.

## One application, one codebase, four days

One of the most important aspects of this bootcamp is how the material is structured.

Rather than learning unit testing, API testing and end-to-end testing through separate, disconnected examples, we work with a single application throughout the entire programme. We write and improve tests against that application, in the same repository, building up our test automation incrementally.

This means that when we move from one testing level to another, you already understand the application and its context. You can see how the different types of tests relate to each other, what each level contributes, and how they fit into a broader test automation approach.

The result is a more immersive and connected learning experience, with practical exercises that build on what you've learned earlier in the bootcamp.

## Who should take this bootcamp?

This bootcamp is intended for software developers, test engineers and other technical practitioners who want to develop or strengthen their practical test automation engineering skills.

It's particularly relevant if you want to move beyond writing individual automated tests and learn how to build a more complete test automation approach, covering different testing levels and integrating automation into your development workflow.

Participants should have some experience with software development and be comfortable working with code. The bootcamp involves hands-on programming exercises throughout the four days.

## Course duration and delivery

The Test Automation Engineering Bootcamp takes four days. It combines explanations, demonstrations, discussions and, most importantly, lots of hands-on exercises.

Throughout the programme, you'll spend a significant amount of time working with the application and codebase, implementing the techniques covered in the sessions and gradually building up its test automation.

The bootcamp can be delivered online or on-site, and the content can be adapted to your team's experience, technology and specific learning goals.
